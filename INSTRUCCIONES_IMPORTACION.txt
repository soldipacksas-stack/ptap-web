PTAP - INTEGRACIÓN DE DATOS REALES NOVIEMBRE 2026

ESTE PAQUETE INCLUYE LA APLICACIÓN Y EL IMPORTADOR. NO HA MODIFICADO RENDER.

ARCHIVOS PRINCIPALES:
 main.py / models.py / database.py / templates/ : aplicación web
 fuente_noviembre_2026.xlsx : Excel original, sin alteraciones
 lector_excel_ptap.py : lector de hojas XLSX
 importar_noviembre.py : importación conservadora con control de duplicados

ANTES DE USAR:
1. Guardar copia de seguridad de la base de datos PostgreSQL en Render.
2. Sustituir en el repositorio los archivos de la aplicación por los del paquete,
   incluyendo templates y los dos scripts, y desplegar en Render.
3. Confirmar que el servicio inicia y las tablas nuevas se crearon.
4. En un entorno con la variable DATABASE_URL configurada (sin compartirla):
      python importar_noviembre.py
   Esto muestra la simulación y NO inserta registros.
5. Revisar reporte_importacion.txt y resolver incidencias antes de importar.
6. Cuando el reporte esté validado, ejecutar UNA VEZ:
      python importar_noviembre.py --aplicar
7. Volver a ejecutar la simulación para verificar que los registros aparecen
   como YA_IMPORTADO o DUPLICADO. Revisar en la interfaz los cuatro módulos.

IMPORTANTE:
- El script compara la base REAL en cada ejecución y NO sobrescribe registros.
- La carga no se ejecuta automáticamente al iniciar Render.
- No copiar un archivo SQLite de pruebas a Render: Render usa PostgreSQL.
- Se conservan valores NA/FS, sin convertirlos en cero.
- Los registros del 4 y 5 de contadores presentan fechas de septiembre:
  quedan fuera de la carga hasta verificar la fecha original.
- Se omiten seis filas de filtros sin tipo de limpieza ni hora final.
- Se omite un registro UF con equipo F211 ambiguo.
- El Excel contiene 747 entradas de Plan Calidad; tres son duplicadas
  bajo la clave actual fecha+turno+zona+parámetro+valor y se omiten.
- La aplicación sigue necesitando completar otras mejoras aprobadas;
  este paquete se enfoca en integración histórica de estos cuatro módulos.

PROTECCIÓN:
No publicar DATABASE_URL, ni claves, ni copias de la base de datos.
